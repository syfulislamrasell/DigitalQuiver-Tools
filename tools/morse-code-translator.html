What is Morse Code?

Morse code represents letters, numbers and punctuation as sequences of short and long signals — dots and dashes — originally designed for telegraph lines in the 1830s-40s and still used today in amateur radio, aviation beacons and emergency signaling, most famously in the distress call "SOS" (... --- ...).

How to use it

  1. Switch to Text → Morse and type a message to see it translated into dots and dashes, with letters separated by spaces and words separated by a forward slash.
  2. Switch to Morse → Text and paste Morse code back in to decode it into readable text.
  3. Expand the reference chart below the tool to look up any letter, number or punctuation mark by hand.

In standard Morse timing, a dash lasts three times as long as a dot, and the length of the pause between symbols, letters and words is what actually separates one character from the next — which is why this tool relies on spaces and slashes to know where one letter or word ends and the next begins. Morse code remains a fun way to learn about early digital communication, and it is still an official requirement for some amateur radio licenses in parts of the world, alongside its ongoing niche use in aviation and marine signaling.
