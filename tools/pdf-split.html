PDF Split (Extract Pages)

Extract a page range from a PDF into a brand new file.

What is PDF Split?

This tool extracts a range of pages from a larger PDF and saves them as a brand new, standalone PDF file — for example, pulling pages 3 through 5 out of a 20-page report.

How to use it

  1. Choose a PDF file; its total page count appears automatically.
  2. Enter the start and end page numbers you want to extract.
  3. Click Extract Pages and then Download Extracted PDF.

This is useful when you only need to share a few pages of a much longer document — a single chapter, one invoice from a batch, or a specific form from a larger packet — without sending the entire original file. Page numbers refer to the position in the original document (page 1 is the first page), and the extracted file keeps the original page order and content unchanged. Like the other PDF tools on this site, extraction happens locally using the pdf-lib library, so your document is never uploaded anywhere.
