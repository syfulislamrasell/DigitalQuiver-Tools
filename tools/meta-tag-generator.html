What is the Meta Tag Generator?

This tool builds the block of HTML <meta> tags that belong in a page's <head> section: the title and description search engines show in results, Open Graph tags that control how the page looks when shared on Facebook or LinkedIn, and Twitter Card tags for X.

How to use it

  1. Fill in the page title, URL and description — the character counter helps you stay within Google's typical ~160 character display limit for descriptions.
  2. Optionally add an author, keywords, a robots directive, and a social share image.
  3. Copy the generated code and paste it into your page's <head>, before the closing </head> tag.

A clear, accurate title and description don't directly boost rankings the way content quality and backlinks do, but they strongly influence whether someone clicks your result once it appears in search — a well-written description acts like ad copy for your page. The Open Graph and Twitter Card tags matter separately: without them, a shared link often shows no image and a generic title, which noticeably reduces clicks when people share your page on social media.
