What is the Image Resizer?

This tool changes an image's pixel dimensions — useful for meeting a platform's exact size requirement, shrinking a huge photo before sharing it, or creating a smaller thumbnail version.

How to use it

  1. Choose an image; its current width and height fill in automatically.
  2. Enter a new width or height. With "Lock aspect ratio" on, changing one automatically adjusts the other so the image doesn't stretch or squash.
  3. Click Resize Image and then Download PNG.

Resizing is different from compressing: this tool changes how many pixels make up the image (its actual dimensions), while the Image Compressor on this site changes how efficiently those pixels are encoded. For the sharpest result when shrinking a photo, resize down rather than up — enlarging a small image beyond its original resolution stretches existing pixels rather than adding real detail, which tends to look soft or blocky. Resizing happens by drawing your image onto an HTML canvas at the new dimensions, entirely on your device, so nothing is uploaded anywhere.
