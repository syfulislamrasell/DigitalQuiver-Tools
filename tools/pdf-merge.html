PDF Merge

Combine multiple PDF files into one, in the order you choose.

    What is PDF Merge?

    This tool combines two or more PDF files into a single document, keeping every page from each file in the order the files are listed.

    How to use it

    1. Choose the PDF files you want to combine (select multiple files at once, or add them one at a time).
    2. Check the list to confirm they're in the order you want them merged.
    3. Click Merge PDFs and then Download Merged PDF.

    Merging PDFs is a common need when combining a cover letter with a resume, assembling several scanned pages into one document, or putting together a multi-part report that was created as separate files. This tool uses the open-source pdf-lib library to copy every page from each source file directly into a new PDF, entirely inside your browser — your files are read locally and never uploaded to any server, which matters for anything containing personal or confidential information.
