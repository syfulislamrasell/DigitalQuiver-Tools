What does PDF Compress do?

This tool re-saves your PDF with an optimized internal structure: it removes duplicate embedded objects, streamlines the document's cross-reference tables, and compresses the object data streams. This can measurably shrink files that were produced with redundant or unoptimized internal structure.

How to use it

  1. Choose a PDF file.
  2. Click Optimize PDF and compare the original and new file sizes.
  3. Click Download Optimized PDF to save the result.

What this doesn't do

Being accurate about scope matters: this tool optimizes the PDF's internal structure, but it does not recompress or downscale the images embedded inside the PDF, which is usually where most of a large PDF's file size actually comes from. For a PDF that's large mainly because of high-resolution scanned images, the reduction here will be modest; for a PDF with redundant structure or uncompressed streams (common in files exported by some office software), the savings can be more noticeable. As with the other PDF tools here, everything runs locally in your browser using the pdf-lib library, so your document is never uploaded anywhere.
