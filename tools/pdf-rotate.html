Rotate PDF

Rotate every page in a PDF by 90, 180 or 270 degrees.

What is Rotate PDF?

This tool rotates every page of a PDF by a fixed angle — useful when an entire document was scanned sideways or upside down and needs to be turned the right way up before sharing or printing.

How to use it

  1. Choose a PDF file; its page count appears automatically.
  2. Pick a rotation angle: 90° clockwise, 180°, or 270° clockwise (equivalent to 90° counter-clockwise).
  3. Click Rotate PDF and then Download Rotated PDF.

The rotation is applied as a display instruction stored in each page (the same mechanism every PDF viewer already understands), rather than by re-drawing the page content, so text stays sharp and selectable and the file size barely changes. This tool rotates every page by the same amount, which covers the most common case of an entire document scanned at the wrong orientation; it does not currently support rotating individual pages by different amounts. As with the other PDF tools here, everything runs locally using the pdf-lib library — your document is never uploaded anywhere.
