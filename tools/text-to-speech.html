Text to Speech (Read Aloud)

Have any text read aloud, using your browser's built-in voices.

Your browser doesn't support the Web Speech API's speech synthesis, so this tool can't run here. It works in most current versions of Chrome, Edge, Safari and Firefox.

What is the Text to Speech tool?

This tool reads any text aloud using your browser's own built-in speech synthesis voices, with adjustable speed and pitch and a choice of any voice your browser/operating system has installed — useful for proofreading your own writing by ear, listening to an article instead of reading it, or as an accessibility aid.

How to use it

  1. Paste or type the text you want read aloud.
  2. Pick a voice, and adjust the speed and pitch if you like.
  3. Click Read Aloud; use Pause or Stop to control playback.

This uses the Web Speech API's speech synthesis feature, built directly into modern browsers — no audio file is generated or uploaded anywhere, and no server is involved at all; your browser's own operating system generates the speech locally. The exact set of available voices depends on your browser and device, since it's your system's own installed voices being listed, not a fixed list we control.
