What is the Image Compressor?

This tool reduces an image's file size by re-encoding it as JPEG or WebP at a quality level you choose, using your browser's built-in image encoder — the same technology behind the "Save As" quality slider in most photo editors, just without installing anything.

How to use it

  1. Choose an image from your device.
  2. Pick an output format and drag the quality slider — lower quality means a smaller file.
  3. Click Compress Image to see the before/after file size, then Download the result.

Smaller images mean faster-loading web pages, quicker uploads, and less storage used, and JPEG or WebP at 70-85% quality is usually visually indistinguishable from the original while cutting file size significantly. WebP typically compresses noticeably smaller than JPEG at the same visual quality, so it's worth comparing both if browser support isn't a concern for your use case. Because everything happens locally on your device using the Canvas API, your photo is never uploaded to any server — which matters if you're compressing anything personal or sensitive.
