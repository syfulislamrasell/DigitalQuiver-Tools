What is Lorem Ipsum?

Lorem Ipsum is scrambled, semi-random Latin text that has been used as filler copy in printing and design since the 1500s. Designers and developers use it to fill mockups, wireframes and templates with realistic-looking paragraphs before the final content is ready, so that layout, font size and spacing can be judged without being distracted by meaningful words.

How to use it

  1. Choose whether you want paragraphs, sentences or a specific number of words.
  2. Set the quantity, and optionally keep the traditional opening line or wrap each paragraph in HTML <p> tags for quick pasting into code.
  3. Click Generate Text and copy the result.

Because Lorem Ipsum text has no real meaning, readers naturally focus on the visual design rather than the words themselves, which is exactly the point: a client reviewing a homepage mockup should be judging the layout, not proofreading placeholder copy. This generator builds new random paragraphs from a fixed pool of classic Lorem Ipsum words each time, so no two results are identical, and the HTML option makes it easy to drop straight into a template file without manually adding tags afterward.
